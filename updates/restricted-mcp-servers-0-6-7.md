## New

- **Keep an MCP server for the work that needs it.** In Settings › MCP servers, turn on "Only automations and rooms that choose it": that server is then available only to the automations and rooms that name it, and the @ menu suggests it only there.

## Fixed

- **Opening another company you own** no longer says "Only this company's owner can use it".
