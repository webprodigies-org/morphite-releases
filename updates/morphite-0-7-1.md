## The rail speaks the sidebar's language

The company rail now uses the same marks as the sidebar: a quiet blue ring while agents are working, an amber dot when a room needs you, and a count of finished work since you last looked.

## Improved

- Jump to latest always lands at the very end of the chat and keeps following new messages.
- Windows: clearer messages when Git can't be used, including where the refused copy lives, and the suggested install now sets up Git for Windows for all users.

## Fixed

- In a short chat, scrolling up no longer folds the message box into its compact form.
