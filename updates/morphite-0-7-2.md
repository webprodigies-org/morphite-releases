## Several accounts per provider

Add more than one Claude Code, Codex or API-key account, choose which one a room uses next to the model, and see each account's limits on the Dashboard. When an account reaches its usage limit, the chat offers to continue on another account with the conversation kept, or to wait for the reset. Continuing automatically is an option you can turn on per provider.

## Improved

- Usage and rate limits from every provider now show a clear notice instead of an error.
- A room shows when an agent is waiting for you even while others work, in the sidebar, the company rail and the phone.

## Fixed

- New GitHub issues reach the board again when another project also links the same repository.
